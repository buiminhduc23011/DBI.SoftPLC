## Task 06.1 — Tag Table editor

Document tab, DataGrid sửa trực tiếp:

```
Default Tag Table                          [+ Add]  [🗑 Delete]  [⬆ Import CSV]
┌──────────────┬───────┬───────────┬──────────────┬──────────┬──────────────────┐
│ Name         │ Type  │ Direction │ Device       │ Address  │ Comment          │
├──────────────┼───────┼───────────┼──────────────┼──────────┼──────────────────┤
│ StartButton  │ Bool  │ Input     │ FactoryIO_3D │ Input_0  │ Nút start tủ điện│
│ StopButton   │ Bool  │ Input     │ FactoryIO_3D │ Input_1  │ Nút stop (NC)    │
│ ConveyorRun  │ Bool  │ Output    │ FactoryIO_3D │ Output_0 │ Contactor băng   │
│ Temperature  │ Real  │ Input     │ Modbus_IO    │ 40001    │ Nhiệt độ lò °C   │
│ CycleCounter │ Int   │ Memory    │ —            │ —        │ Đếm sản phẩm     │
└──────────────┴───────┴───────────┴──────────────┴──────────┴──────────────────┘
```

- `Type`: ComboBox `Bool | Int | Real`
- `Direction`: ComboBox `Input | Output | Memory`
- `Device`: ComboBox nạp từ `Project.Devices` — **vô hiệu hoá** khi `Direction = Memory`
- `Address`: TextBox, placeholder gợi ý theo driver (`Input_0` cho FactoryIO, `40001` cho Modbus, `D100` cho Delta)
- Validate **ngay khi gõ**: ô sai viền đỏ `#C72C3B` + tooltip lý do

Nhiều tag table: mỗi table một tab. TIA khuyến nghị mỗi subroutine một tag table riêng — Studio cho phép nhưng không ép.

## Task 06.2 — Validation (dùng lại validator phase-01)

| Luật | Mức |
|---|---|
| Tên là C# identifier hợp lệ | 🔴 Error |
| Tên không trùng **toàn project** (kể cả khác hoa/thường — `MemorySnapshot` dùng `OrdinalIgnoreCase`) | 🔴 Error |
| Tên không phải từ khoá C# | 🔴 Error |
| `Direction != Memory` → `Device` phải tồn tại | 🔴 Error |
| `Direction != Memory` → `Address` không rỗng | 🔴 Error |
| Hai tag cùng `(Device, Address)` | 🟡 Warning — hợp lệ nhưng đáng ngờ |
| Tag khai báo nhưng không dùng trong code nào | 🟡 Warning *(sau phase-08)* |

Lỗi hiển thị ở Inspector → tab **Information**. Double-click nhảy tới ô sai.

## Task 06.3 — `IoCodeGenerator`

**File:** `src/DBI.Controller.Studio/Services/CodeGen/IoCodeGenerator.cs`

Sinh `Generated/IO.g.cs` từ toàn bộ tag của mọi table:

```csharp
// <auto-generated>
//     File này do DBI.Studio sinh tự động từ Tag Table.
//     MỌI THAY ĐỔI THỦ CÔNG SẼ BỊ GHI ĐÈ khi build lại.
//     Nguồn: MyMachine.dbiproj — sinh lúc 2026-07-26 23:16
// </auto-generated>
#nullable enable

namespace DBI.Controller.SDK.IO;

public partial class IOContainer
{
    /// <summary>Nút start tủ điện — FactoryIO_3D / Input_0</summary>
    public bool StartButton => GetBool("StartButton");

    /// <summary>Contactor băng — FactoryIO_3D / Output_0</summary>
    public bool ConveyorRun { get => GetBool("ConveyorRun"); set => SetBool("ConveyorRun", value); }

    /// <summary>Nhiệt độ lò °C — Modbus_IO / 40001</summary>
    public float Temperature => GetFloat("Temperature");

    /// <summary>Đếm sản phẩm — bộ nhớ nội</summary>
    public int CycleCounter { get => GetInt("CycleCounter"); set => SetInt("CycleCounter", value); }
}
```

**Quy tắc sinh:**

| Direction | Accessor | Lý do |
|---|---|---|
| `Input` | chỉ `get` | Ghi vào input = lỗi compile, đúng ngữ nghĩa PLC |
| `Output` | `get` + `set` | |
| `Memory` | `get` + `set` | |

| DataType | Method |
|---|---|
| `Bool` | `GetBool` / `SetBool` |
| `Int` | `GetInt` / `SetInt` |
| `Real` | `GetFloat` / `SetFloat` |

- `Comment` → XML doc comment (hiện trong IntelliSense tooltip ở phase-08)
- Sinh vào **cùng namespace** `DBI.Controller.SDK.IO` để `partial` ghép đúng với [IOContainer.cs](../../src/DBI.Controller.SDK/IO/IOContainer.cs)

## Task 06.4 — Thời điểm sinh code
